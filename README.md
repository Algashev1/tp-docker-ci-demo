# Трекер ревью и рефайнментов (демо: Docker + CI/CD)

Учебный проект курса «Технологии программирования»: веб-приложение, в котором преподаватель ведёт
расписание спринт-ревью и бэклог-рефайнментов команд и пишет комментарии по итогам встреч.

- **Команды**: добавить по одной или списком, проект и состав с ролями.
- **Встречи**: спринт-ревью и рефайнменты, повтор каждые N недель на несколько спринтов, статусы.
- **Календарь** на месяц и список ближайших встреч на 2 недели.
- **Комментарии** по итогам каждой встречи.
- **Доступ**: смотреть может любой, добавлять и менять данные - только преподаватель после входа.

Стек: FastAPI + PostgreSQL (бэкенд), статический HTML/JS за nginx (фронтенд), docker compose, GitHub Actions.

## Запуск

```bash
cp .env.example .env
docker compose up -d --build
```

Откройте http://localhost:3000. Без входа сайт работает в режиме просмотра. Нажмите «Войти»:
в первый раз приложение попросит задать пароль преподавателя (8-64 символа), дальше вход только по нему.

## Запуск готовой версии без сборки

После каждого зелёного прогона в `main` образы публикуются в GitHub Container Registry:

```bash
cp .env.example .env
docker compose pull backend frontend
docker compose up -d --no-build
```

## Тесты

```bash
docker compose exec backend pytest -v
```

Тесты используют отдельную базу `app_test`, рабочие данные не затрагиваются.
