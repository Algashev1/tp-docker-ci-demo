# AGENTS.md

Инструкции для ИИ-ассистентов (Claude Code, Codex, Cursor, GigaCode и др.), работающих
с этим репозиторием.

## Проект

Трекер спринт-ревью и бэклог-рефайнментов: FastAPI + PostgreSQL (`backend/`),
статический HTML/JS за nginx (`frontend/`), docker compose. Тесты: `docker compose exec backend pytest -v`.

## Безопасность - обязательные правила

1. **Права проверяются на сервере.** Каждый новый POST/PUT/PATCH/DELETE получает
   `dependencies=[Depends(require_auth)]`. Скрыть кнопку на фронтенде недостаточно.
2. **SQL - только с параметрами** (`%s`). Никаких f-строк и конкатенации в запросах.
3. **Пользовательский текст на фронтенде - через `esc()`.** Не вставлять данные через
   `innerHTML` без экранирования.
4. **Никаких секретов в коде.** Пароли, ключи, токены - только из переменных окружения.
   Не создавать и не коммитить `.env`.
5. **Не отключать проверки безопасности:** проверку сертификатов (`verify=False`), CSP,
   флаги cookie `HttpOnly`/`SameSite`. Не ставить CORS `*`.
6. **Новые зависимости** - только существующие, широко используемые пакеты; назвать
   пакет и версию в описании изменения.
7. **Не выставлять наружу** порты БД и бэкенда в `docker-compose.yml`.
8. На каждое изменение прав доступа - тест в `backend/tests/`, что без входа возвращается 401.

Если задача требует нарушить одно из правил - остановиться и спросить человека.
