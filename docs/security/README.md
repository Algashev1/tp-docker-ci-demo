# Безопасность: учебные материалы к лекции 7

Эта папка - разбор типичных уязвимостей веб-приложений на примере нашего трекера.
Материал учебный: показываем **ошибку** и рядом **как сделано правильно** в этом репозитории.

> Здесь нет готового «взламываемого» стенда и нет рабочих эксплойтов.
> Каждый пример - это пара «так делать нельзя» / «так правильно», чтобы вы нашли и
> починили такие же места в своём проекте.

## Что где лежит

| Файл | О чём |
|------|-------|
| [antipatterns.md](antipatterns.md) | 7 уязвимостей: ошибка, почему опасно, как исправлено у нас |

| [local-scan.md](local-scan.md) | команды локальной проверки: gitleaks, pip-audit, bandit, trivy |

## Как это проверяется автоматически

- `backend/tests/test_security.py` - тесты: инъекция не ломает БД, пароль хранится хешем,
  чужой пароль отклоняется, данные отдаются как данные, а не как исполняемый HTML.
- Job `security` в [CI](../../.github/workflows/ci.yml) - gitleaks, pip-audit, bandit, trivy.
  Эти проверки сейчас стоят в режиме предупреждений (`continue-on-error`), чтобы показать
  находки, но не блокировать сборку. В реальном проекте их делают блокирующими.
